NexusRAG / Pipeline guide

From documents to cited answers

Documents become searchable passages. Each question retrieves passages, generates an answer with Ollama and checks its source numbers.

This guide explains the default settings. It does not show a live run.

Default settings and checks
Documents
PDF parsing reads text without OCR. DOCX parsing reads body paragraphs and tables, including nested table text, in document order. Headers, footers and image text are not extracted; table layout is not preserved. Parsed documents and passage vectors are saved; BM25 stays in memory, so run one application worker.
Retrieval
Each search returns up to 50 candidates. Rank fusion uses fixed query-shape weights and selects up to eight passages. Feedback is enabled by default: when results exist and the best dense cosine score is below 0.55, up to ten frequent non-query terms from the first five passages expand the question. If new terms are found, both searches run once more and both passes are merged before generation. Otherwise, the first results are kept.
Generation
The default Ollama model is llama3.2:3b. Remove duplicate passage IDs, then include up to five complete source passages within a 6,000-character formatted context limit. Stop before the first passage that does not fit. The question and instructions sit outside that limit. Empty indexes, no matches or no passages that fit return a message without calling Ollama. Generation failures retain supplied sources with zero confidence and a warning; answer checks are skipped.
Citations and confidence
Citation checks warn about missing or invalid citations. They validate source numbers, not factual support. Default confidence combines normalized retrieval scores and the fraction of sources cited. It does not establish correctness.
Optional NLI
Natural language inference compares each answer sentence with every supplied source. A best entailment score of at least 0.5 counts as grounded; confidence becomes the fraction of grounded sentences. NLI reports scores and warnings without rewriting the answer or running generation again. It does not verify each inline citation. Enable it with SELF_CORRECTION_GROUNDING_ENABLED=true.

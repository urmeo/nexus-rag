NexusRAG / Pipeline guide

From documents to cited answers

Documents become searchable passages. Each question retrieves passages and asks local Ollama for an answer with numbered sources.

This guide explains the default settings. It does not show a live run.

Index documents

Once per upload

  1. 1

    Read the document

    Extract text from PDF, DOCX, Markdown, or UTF-8 text files.

  2. 2

    Split into passages

    Keep overlapping text passages with document names and available section and page details.

  3. 3

    Build passage indexes

    Save BGE-small vectors for meaning search and build a BM25 keyword index.

Answer a question

Search the saved passages each time

  1. 1

    Retrieve passages

    Combine meaning search and BM25 keyword rankings to select relevant passages.

    Optional: one feedback search. When dense similarity is low, add terms from the first results and merge both searches before generation.

  2. 2

    Generate and check

    Ollama writes an answer from up to five source passages. Citation checks remove out-of-range references.

    Optional NLI check. Score sentence support against the sources. Off by default.

  3. 3

    Read the answer and sources

    See numbered citations, source excerpts, confidence, and warnings. Read the passages to check the claims.

Default settings and checks
Documents
PDF parsing reads text without OCR. DOCX parsing reads paragraphs. Parsed documents and passage vectors are saved; BM25 stays in memory, so run one application worker.
Retrieval
Each search returns up to 50 candidates. Rank fusion uses fixed query-shape weights and selects up to eight passages. Feedback is enabled by default: it runs once when results exist and the best dense cosine score is below 0.55. Up to ten frequent non-query terms from the first five passages expand the question. Both searches run again, and both passes are merged before generation.
Generation
The default Ollama model is llama3.2:3b. After duplicate passage IDs are removed, keep up to five source passages. Formatted source context is clipped at 6,000 characters when needed, then a truncation marker is added. The question and instructions sit outside that limit. Empty indexes or no matches return a message without calling Ollama. Generation failures retain sources with zero confidence and a warning; answer checks are skipped.
Citations and confidence
Citation checks warn about missing or invalid citations. They validate source numbers, not factual support. Default confidence combines normalized retrieval scores and the fraction of sources cited. It does not establish correctness.
Optional NLI
Natural language inference compares each answer sentence with every supplied source. A best entailment score of at least 0.5 counts as grounded; confidence becomes the fraction of grounded sentences. NLI reports scores and warnings without rewriting the answer or running generation again. It does not verify each inline citation. Enable it with SELF_CORRECTION_GROUNDING_ENABLED=true.
